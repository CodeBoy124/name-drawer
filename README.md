# Name drawer

Imagine the following. You've got an app with three fields and a button:

- (field) possible names

- (field) your name

- (field) seed

- (button) get the person that has been assigned to you

You're using this tool with a group. Each person in that group fills in the exact same possible names (everyone from the group) and when someone inserts their own name, they get assigned one other person that will not be picked by someone else.

This is the vision I have for this simple app. It will allow you to draw a name, make/do something for that person and ensures everyone gets something.

## Technical details

To keep this app cheap and simple, I want to make it a static html page hosted on github pages. This means that when someone "roles" a names, all others must have the same seed/starting point.
